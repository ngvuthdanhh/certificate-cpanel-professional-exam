# 🛣️ Study Roadmap  

## Week 1 — Foundation  
- Overview of cPanel/WHM  
- Install test server (VM or VPS)  
- Practice account creation & DNS basics  

## Week 2 — Web & Database Services  
- Configure EasyApache 4  
- Switch PHP handlers  
- Setup and manage MySQL/MariaDB  

## Week 3 — Email & Security  
- Configure Exim + SpamAssassin  
- Enable DKIM/SPF records  
- SSL/TLS installation  
- Configure cPHulk & firewall basics  

## Week 4 — Backup & Troubleshooting  
- Configure backups  
- Test account restore  
- Analyze Apache & Exim logs  
- Practice CLI tools for diagnostics  

## Week 5 — Mock Exam  
- Review all modules  
- Complete hands-on labs  
- Go through practice Q&A
