# 📖 Glossary of Key Terms  

- **WHM (WebHost Manager):** Administrative interface for managing cPanel servers.  
- **cPanel:** End-user control panel for managing hosting accounts.  
- **EasyApache 4:** Tool for managing Apache, PHP, and related modules.  
- **MultiPHP:** System for running multiple PHP versions with different handlers.  
- **Exim:** Mail Transfer Agent (MTA) used by cPanel.  
- **SpamAssassin:** Spam filtering system for incoming mail.  
- **DKIM/SPF:** Email authentication mechanisms.  
- **cPHulk:** Brute-force protection tool in cPanel.  
- **MariaDB/MySQL:** Database management systems.  
- **Backup Restoration:** Process of restoring accounts and data after failure.
