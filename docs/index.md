# 📘 cPanel & WHM Professional Exam — Overview  

The **cPanel & WHM Professional Exam** validates the candidate’s knowledge in:  
- Managing **cPanel/WHM servers**  
- Handling **accounts, DNS, and email**  
- Configuring **Apache, PHP, MySQL/MariaDB**  
- Implementing **security and backups**  
- Troubleshooting and supporting end-users  

This repository provides:  
- 📚 **Notes** — Detailed study notes per exam domain  
- 💻 **Labs** — Hands-on practice scenarios  
- 📎 **Extras** — Tips, FAQ, resources  
- 🧾 **Docs** — Syllabus, roadmap, references, glossary
