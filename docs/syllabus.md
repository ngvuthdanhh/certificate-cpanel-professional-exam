- MySQL/MariaDB management  

## 5. Backup & Recovery  
- Configuring backup systems  
- Restoring accounts and files  
- Disaster recovery workflow  

## 6. Troubleshooting & Support  
- Log file analysis  
- Common service errors (Apache, Exim, MySQL)  
- CLI utilities for diagnosis
