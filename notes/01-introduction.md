# Module 01 — Introduction to the Exam & Environment  

## 🎯 Objectives  
- Understand the structure of the cPanel Professional Exam  
- Get familiar with the testing environment (VM, VPS, or dedicated server)  
- Learn basic navigation in WHM and cPanel  

## 🗂️ Key Topics  
- WHM vs cPanel: roles and differences  
- Exam domains (server management, email, security, etc.)  
- User hierarchy: root → reseller → end user  

## 🛠️ Practice  
- Log into WHM and cPanel  
- Explore menus and features  
- Identify where main services (Apache, Exim, MySQL) are configured
