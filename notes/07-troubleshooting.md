# Module 07 — Troubleshooting  

## 🎯 Objectives  
- Diagnose and fix common issues  

## 🗂️ Key Topics  
- Log files:  
  - Apache → `/usr/local/apache/logs/`  
  - Exim → `/var/log/exim_mainlog`  
  - cPanel → `/usr/local/cpanel/logs/error_log`  
- Restarting services from CLI and WHM  
- Resolving DNS, mail, and web errors  

## 🛠️ Practice  
- Tail Apache error log while loading a website  
- Use WHM to restart Exim/MySQL  
- Diagnose a mail delivery failure
