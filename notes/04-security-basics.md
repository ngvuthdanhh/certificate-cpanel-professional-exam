# Module 04 — Security Basics  

## 🎯 Objectives  
- Secure server and accounts with built-in cPanel tools  

## 🗂️ Key Topics  
- SSL/TLS installation via AutoSSL  
- cPHulk brute-force protection  
- CSF (ConfigServer Security & Firewall) if available  
- Two-Factor Authentication (2FA) for cPanel/WHM  

## 🛠️ Practice  
- Install AutoSSL for a domain  
- Enable and configure cPHulk protection  
- Configure 2FA for WHM login
